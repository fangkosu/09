## 3. 問題回答

### **問題一：測試一中，整理後的桌遊串列有 4 筆資料，為什麼桌遊費用應以 3 人計算？直接把字串拆成 list，和再轉成 set，各自保留了什麼、失去了什麼？**

* **為什麼以 3 人計算**：
  在測試一的原始資料中，桌遊的原始報名輸入包含了兩個相同的名字（不區分大小寫的 `amy`）。因為在現實中「同一個人重複報名同一場活動」只需繳交一次費用，所以重複的報名資訊在計算費用時必須進行「去重（De-duplication）」。去重後的實際報名人數為 3 人（`amy`, `ben`, `cora`），因此費用應以 3 人計算（$3 \times 120 = 360$ 元）。

* **List（串列）與 Set（集合）的對比**：
  * **直接拆成 List**：
    * **保留了**：元素的「原始順序」以及「重複的元素」（例如保留了兩個 `amy`）。
    * **失去了**：無法自動去除重複值，且在進行名單比對或搜尋時效率較低。
  * **再轉成 Set**：
    * **保留了**：所有不重複的「唯一元素值」，非常適合用來做集合運算（如交集、聯集、差集）。
    * **失去了**：元素的「原始順序」（`set` 是無序的），以及重複的資料個數。

### **問題二：測試三中，兩場活動只有 3 位不同的人，為什麼是 6 人次、總應收仍是 600 元？請用集合關係與算式說明。**

* **人次與不重複人數的差別**：
  「不重複人數」是指獨立的自然人個數。而「報名人次」與「應收費用」是以**活動**為單位進行累加的。在測試三中，3 位參加者（`amy`, `ben`, `cora`）皆同時報名了「桌遊體驗」與「電影欣賞」兩場活動。

* **集合關係與算式說明**：
  * 令桌遊體驗的去重集合為 $A = \{\text{amy}, \text{ben}, \text{cora}\}$，人數 $n(A) = 3$。
  * 令電影欣賞的去重集合為 $B = \{\text{amy}, \text{ben}, \text{cora}\}$，人數 $n(B) = 3$。
  * 兩場活動完全重疊，因此共同參加者（交集）為 $A \cap B = \{\text{amy}, \text{ben}, \text{cora}\}$，人數 $n(A \cap B) = 3$。
  * 總不重複人數（聯集）為 $n(A \cup B) = n(A) + n(B) - n(A \cap B) = 3 + 3 - 3 = 3$ 人。
  * **總報名人次**：為兩場活動報名人數的直接加總，即 $n(A) + n(B) = 3 + 3 = 6$ 人次。
  * **總應收金額算式**：
    $$\text{總費用} = [n(A) \times \text{桌遊單價}] + [n(B) \times \text{電影單價}]$$
    $$\text{總費用} = [3 \times 120] + [3 \times 80] = 360 + 240 = 600 \text{ 元}$$
  因此，即使總不重複人數只有 3 人，因為每個人都參加了兩場活動，所以產生的總報名人次為 6 人次，總應收金額依然是 600 元。
